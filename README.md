# RiverSeg_Benchmark
RiverSeg Benchmark was curated from FloodNet and OpenEarthMap. To focus the benchmark on river boundary relevant scenes, the images with less than 5% water or floodwater coverage are filtered out. The original class labels from both datasets are then remapped to a unified five-class taxonomy. The representative images from both sources were selected and uploaded to dataset/Samples

Water-rich filtering, label remapping, zero-shot evaluation and SAM2 fine-tuning scripts will be uploaded.
